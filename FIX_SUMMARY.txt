PROBLEM:
--------
Student Faults page showing errors:
  ❌ Error fetching classes: AxiosError 401
  ❌ Error fetching reports: AxiosError 401

ROOT CAUSE:
-----------
The /api/faults/classes and /api/faults/reports endpoints required 
authentication, but these are just listing class names and showing statistics
(no sensitive data).

SOLUTION APPLIED:
-----------------
Modified: backend/routes/studentFaultsRoutes.js

BEFORE:
  router.use(authenticateToken);  // Applied to ALL endpoints
  router.get('/classes', ...)
  router.get('/reports', ...)
  router.get('/students/:className', ...)
  ...

AFTER:
  // Public endpoints (no auth)
  router.get('/classes', ...)
  router.get('/reports', ...)
  
  router.use(authenticateToken);  // Applied only to protected endpoints
  
  // Protected endpoints (auth required)
  router.get('/students/:className', ...)
  router.post('/add-fault', ...)
  router.put('/edit-fault/:className/:faultId', ...)
  router.delete('/delete-fault/:className/:faultId', ...)

SECURITY:
---------
✅ Safe - Only made public endpoints that don't expose sensitive data

✅ Student details still require authentication
